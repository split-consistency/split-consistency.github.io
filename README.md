## Split Consistency Blogs

This repository contains a static website with links to our split consistency blogs.

### Split Consistency

Split consistency checks whether a model's direct probability forecast agrees with the forecast obtained by splitting a question into cases and combining their probabilities using the law of total probability.

### First Post: Decision Models

The first post, [Split Consistency in Decision Models](decision.html), explores this idea through evaluations and interactive visualizations.

### Development

To view the website locally, open `index.html` in a browser. The site uses static HTML, CSS, and JavaScript.
